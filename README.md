# 🎮 Tic-Tac-Toe Game

A modern and interactive Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

The game provides two playing modes: Player vs Player and Player vs AI, with a clean interface, score tracking, win highlighting, and responsive design.

## ✨ Features

- 🎮 Player vs Player mode
- 🤖 Player vs AI mode
- ❌ X and ⭕ O gameplay
- 🧠 AI with basic winning and blocking logic
- 🏆 Automatic winner detection
- ✨ Highlights the winning combination
- 🤝 Draw detection
- 📊 Score tracking for:
  - X wins
  - O wins
  - Draws
- 🔄 Restart the game at any time
- 🔒 Prevents invalid moves after the game ends
- 📱 Responsive design for smaller screens
- 🎨 Modern dark green interface
- ⚡ Interactive gameplay powered by JavaScript

## 🛠️ Technologies Used

- **HTML5** — Game structure and semantic elements
- **CSS3** — Styling, responsive layout, animations, shadows, and visual effects
- **JavaScript (ES6)** — Game logic, AI behavior, win detection, score tracking, and interactions

## 🤖 AI Logic

The Player vs AI mode uses a simple rule-based strategy.

The AI:

1. Checks whether it can win on the current move.
2. Checks whether the player is about to win and blocks the move.
3. If neither condition applies, the AI selects an available square.

This creates a simple interactive opponent without using external libraries.
